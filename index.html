01 — Tentang Saya

Dari baris kode,
lahir karya nyata

Ridho Santoso

Saya adalah Ridho Santoso, siswa kelas XI di SMAN 2 Cikarang Utara yang sejak awal masuk SMA sudah terjun langsung ke dunia web development. Bukan sekadar belajar teori — setiap ilmu langsung saya terapkan lewat proyek nyata.

Spesialisasi utama saya adalah Front-End Development — membangun antarmuka web yang bersih, responsif, dan fungsional menggunakan HTML, CSS, dan JavaScript. Saya juga terbiasa mengintegrasikan sisi backend sederhana dengan PHP dan database SQL, serta memanfaatkan Google Apps Script untuk otomasi berbasis Google Sheets.

Setiap proyek yang saya kerjakan lahir dari keinginan untuk memecahkan masalah nyata di lingkungan sekolah — mulai dari transparansi kelulusan siswa hingga efisiensi sistem absensi harian.

04 — Spesialisasi

Front-End adalah
rumah saya

Bidang yang paling saya kuasai dan gemari adalah Front-End Development. Saya percaya bahwa antarmuka yang baik bukan hanya soal tampilan — tapi tentang bagaimana pengguna merasakan pengalaman berinteraksi dengan sebuah produk digital.

Dimulai dari memahami struktur HTML yang semantik, mengolah CSS hingga animasi yang halus, lalu menghidupkan semuanya dengan logika JavaScript — itulah alur kerja yang saya nikmati setiap harinya.

Saya juga tidak takut masuk ke sisi backend sederhana. Kemampuan PHP dan MySQL saya gunakan untuk membangun sistem yang benar-benar fungsional, sementara Google Apps Script membuka jalan untuk otomasi cepat tanpa server fisik.
